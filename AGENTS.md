# ProofLayer Agent Instructions

Before changing this repository:

1. Verify the repository path, expected branch, expected HEAD, and working-tree state.
2. Read every file under `docs/agent/`.
3. Follow the task-specific prompt for the requested scope and deliverables.
4. Preserve the ProofLayer trust and proof boundaries.
5. Run the repository build and full offline test suite before completion.
6. Keep runtime `workspace/` data ignored, private, and untracked.
7. Never push unless the user explicitly requests it.

If the baseline or safety assumptions do not match the task, stop before editing and report the mismatch.
